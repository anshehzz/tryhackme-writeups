# Defensive Security Intro — TryHackMe

**Difficulty:** Info  
**Category:** Defensive Security / Blue Team  
**Completed:** May 2026  

## Overview
An introductory room covering defensive security concepts, 
where I protected FakeBank from an ongoing cyberattack.

## What I Learned
- What defensive security means and who does it (SOC analysts, 
  DFIR teams, malware analysts)
- How Security Operations Centers (SOC) work
- Introduction to SIEM tools — software that collects and 
  analyzes security alerts
- Basics of Digital Forensics and Incident Response (DFIR)
- How threat intelligence is used to predict and prevent attacks

## Key Concepts
- **SOC (Security Operations Center):** A team that monitors 
  systems 24/7 for threats
- **SIEM:** Collects logs from across a network and flags 
  suspicious activity
- **DFIR:** Investigating after an attack to understand what 
  happened and recover
- **Malware Analysis:** Studying malicious software to understand 
  how it works

## Key Takeaway
Defensive security is just as important as offensive security. 
Understanding how defenders think is essential for anyone 
pursuing cybersecurity.
