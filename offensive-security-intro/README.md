# Offensive Security Intro — TryHackMe

**Difficulty:** Easy  
**Category:** Offensive Security  
**Completed:** May 2026  

## Overview
An introductory room that simulates ethical hacking by targeting 
a fake bank website (FakeBank) in a safe, legal environment.

## What I Learned
- The difference between offensive and defensive security
- How ethical hackers think and operate
- How attackers discover hidden pages on websites using 
  directory enumeration
- Why authorization is the most important rule in ethical hacking —
  never test systems without permission

## Tools and Concepts Introduced
- Directory enumeration (finding hidden web pages)
- Web application structure basics
- Ethical hacking methodology

## Key Takeaway
Offensive security is about thinking like an attacker to 
help defenders build stronger systems. Even basic techniques 
like scanning for hidden directories can reveal serious 
vulnerabilities in poorly configured websites.
