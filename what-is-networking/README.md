## Overview
A beginner-friendly room covering the core concepts of 
how computers communicate with each other over networks.

## What I Learned
- What a network is and why networks exist
- Different types of networks: LAN, WAN, and the Internet
- How devices are identified using IP addresses and MAC addresses
- The basics of how data travels across networks (packets)
- Introduction to the OSI model — the 7-layer framework that 
  describes how network communication works

## Key Concepts
- **IP Address:** A unique address that identifies a device on a network
- **MAC Address:** A hardware identifier built into every network device
- **Packet:** A small chunk of data sent across a network
- **OSI Model:** A 7-layer model (Physical → Data Link → Network → 
  Transport → Session → Presentation → Application)

## Key Takeaway
Networking is the backbone of everything in cybersecurity. 
Understanding how data moves between devices is essential 
before learning how to secure or attack those communications.
